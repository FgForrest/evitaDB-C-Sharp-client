// `PriceContentMode` stays reachable through its type alias below as `PriceContentMode.None`. It is the only

// The `using static` directives above import the enum *members* (`Counts`), but not the enum *type*, so a

// type names into scope as well, so both the bare and the qualified spelling work. Aliases rather than plain
// namespace imports, because importing e.g. `EvitaDB.Client.Queries.Order` would make `Random` ambiguous
// with `System.Random`.
